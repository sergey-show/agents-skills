# Rules — coding-standards

1. Project local style beats this baseline when they conflict.
2. Do not impose a single language's idioms on another language.
3. Never "fix" style by rewriting unrelated code.
4. Prefer small diffs that improve clarity over grand renames unless asked.
5. Security and correctness outrank aesthetics.
