# Approaches — coding-standards

## Principles
1. Readability first
2. KISS — simplest solution that works
3. DRY — extract real duplication, not imagined
4. YAGNI — no speculative features

## Naming
- Variables: descriptive nouns
- Functions: verb-noun; predicates `is/has/can`
- Avoid single-letter names outside tiny scopes

## Review checklist
- [ ] Names clear without comments
- [ ] No unnecessary abstraction
- [ ] Errors handled at trust boundaries
- [ ] Magic values named or justified
- [ ] Consistent with local project style (wins over this baseline)
