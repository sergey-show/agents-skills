# Rules — design-auditor

1. Do not claim a clean audit without stating what was and was not checked.
2. Do not silently redesign during an audit — document first.
3. Dual assessment on web when tools exist; banner any degradation.
4. Assessment A finishes before B contaminates design judgment (or isolate via subagents).
5. Every issue needs location + impact + recommendation.
6. Detector empty ≠ design quality proven.
7. Question (or skip line) closes the run — report alone is incomplete.
8. Do not invent console/detector findings.
9. Stop local servers you started unless the user asks to keep them.
10. Native platforms: design review only; say browser detect did not apply.
