# Audit dimensions (0–4)

| Dimension | 0 | 2 | 4 |
|-----------|---|---|---|
| Accessibility | Fails WCAG A | Partial effort | WCAG AA met, AAA leaning |
| Performance | Severe jank/unoptimized | Some work, gaps | Lean and fast |
| Theming | Hard-coded everything | Tokens inconsistent | Full tokens + themes |
| Responsive | Desktop-only | Works rough on mobile | Fluid + touch OK |
| Implementation integrity | Systemic drift/slop | Several verified issues | Coherent product-specific |

Bands: 18–20 Excellent · 14–17 Good · 10–13 Acceptable · 6–9 Poor · 0–5 Critical.
