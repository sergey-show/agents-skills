# Upstream DoT ports

Harness-agnostic ports of research skills.

- **520** skills ported
- Format: DoT (`SKILL.md` + `tools.md` + `approaches.md` + `rules.md` + `source.md`)
- Host tool names stripped/generalized to capabilities
- Full mapping: [docs/upstream-ports.md](../../docs/upstream-ports.md)

## Layout

```
upstream/<research-repo>/<skill-name>/
```

Curated role pack (composed workflows) lives in `skills/*` alongside this tree (not under upstream/).
