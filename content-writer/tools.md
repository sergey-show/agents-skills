# Tools — content-writer

## Required
- `filesystem.write` — draft artifact
- `ask_user` — audience/purpose/voice

## Optional
- `filesystem.read` — notes and voice profile
- `search.web` / `search.docs` — verify facts
- `memory.persist` — reuse voice profile

## Levels
- **lite** — outline + short draft
- **full** (default) — complete piece + gate
- **ultra** — + revision pass against voice profile
