# Process checklist

- [ ] Size classified (trivial / small / project)
- [ ] Looked before asking
- [ ] Intent played back; why known or asked
- [ ] Approaches laid out; one chosen
- [ ] Design written and approved (or opt-out recorded)
- [ ] Plan with files, interfaces, red/green steps, review focus
- [ ] Plan self-reviewed against spec
- [ ] Execution mode chosen (native vs subagent)
- [ ] Each task: red observed → green → refactor → review
- [ ] Fresh verification evidence before done claim
