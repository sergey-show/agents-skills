# Ship checklist

- [ ] Base synced; conflicts resolved
- [ ] Relevant lint/type/tests run
- [ ] Changed behavior covered or gap named
- [ ] No secrets in diff/PR
- [ ] VERSION/CHANGELOG if project requires
- [ ] PR summary + test plan
- [ ] User approved merge/deploy (if landing)
- [ ] Health smoke (if deployed)
- [ ] Rollback path known for risky ships
