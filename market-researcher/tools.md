# Tools — market-researcher

## Required
- `search.web` — market/competitor/investor sources
- `filesystem.write` — brief artifact

## Optional
- `search.docs` / `browser.navigate` — deep-read filings and product pages
- `ask_user` — decision context
- `reach.social` — traction/sentiment leads (not proof)

## Levels
- **lite** — 1-page decision brief
- **full** (default) — modes + sources + recommendation
- **ultra** — sizing model with explicit assumptions + competitor matrix
