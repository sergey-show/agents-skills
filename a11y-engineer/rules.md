# Rules — a11y-engineer

1. Automated clean ≠ conformant — always do keyboard (+ SR when shipping major UI).
2. Verify automated findings before treating them as real.
3. Prefer native semantics over ARIA reinventing.
4. Do not ship known Critical keyboard/SR blockers without explicit user deferral.
5. Fixes must be re-audited.
6. No harness-specific tool names.
