# Tools — search-first

## Required
- `search.code` / `filesystem.read` — in-repo reuse

## Optional
- `search.web` / `search.docs` — registries and docs
- `shell.exec` — package manager queries when available
- `ask_user` — license/vendor constraints
- `subagent.spawn` — full-mode parallel research

## Levels
- **lite** — mental checklist + repo grep
- **full** (default) — repo + registry + web
- **ultra** — parallel researcher worker + comparison table
