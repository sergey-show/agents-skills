# DESIGN.md outline (portable)

```markdown
# Design System: [Product]
## Dials
Creativity / Density / Variance / Motion Intent — with levels and why

## 1. Visual Theme & Atmosphere
Mood, density, aesthetic philosophy (evocative, specific)

## 2. Color Palette & Roles
Name + hex + role. One accent. Banned colours.

## 3. Typography Rules
Display / body / mono. Scale. Tracking. Banned faces.

## 4. Component Stylings
Buttons, cards, inputs, nav, loaders, empty, error — shape, colour, states, when-not.

## 5. Hero / Primary Surfaces
Composition rules for the first viewport (brand-first, hero budget).

## 6. Layout Principles
Grid, containment max-width, section rhythm, no-overlap, responsive collapse.

## 7. Motion & Interaction Intent
What animates, spring/easing, reduced-motion, hardware rules (transform/opacity).

## 8. Content Rules
Voice, banned clichés, honesty about metrics/quotes/logos.

## 9. Anti-Patterns (Banned)
Explicit list agents must not reintroduce.
```

Pair with PRODUCT.md for users, jobs, and non-goals.
