# Rules — frontend-engineer

1. Reuse design-system components before inventing new ones.
2. Build keyboard/semantics into the first version — not a polish pass only.
3. Do not introduce a new CSS/state framework without explicit approval.
4. Match existing file/test colocation conventions.
5. Verify with project commands; don't invent a parallel toolchain.
6. Above-the-fold LCP content must not be carelessly lazy-loaded.
7. No harness-specific tool names.
