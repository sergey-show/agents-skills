# Tools — research-analyst

## Required
- `search.web` — multi-query coverage
- `filesystem.write` — durable report artifact
- `ask_user` — goal/depth clarification

## Optional
- `search.docs` — deep-read pages
- `browser.navigate` — JS-rendered sources
- `reach.social` — platform-native leads
- `subagent.spawn` — parallel sub-question workers

## Levels
- **lite** — 5–10 sources, short report
- **full** (default) — 15–30 sources, themed sections
- **ultra** — parallel workers + contradiction matrix + confidence per claim
