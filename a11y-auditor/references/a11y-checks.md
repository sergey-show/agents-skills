# A11y check card

- [ ] `lang` on html
- [ ] One logical h1; no skipped levels
- [ ] Landmarks present
- [ ] Icon buttons have accessible names
- [ ] Inputs have labels
- [ ] Focus visible ≥3:1
- [ ] No keyboard trap (except modal by design)
- [ ] Alt or decorative aria-hidden on images
- [ ] Contrast AA
- [ ] Tap targets adequately sized/spaced
- [ ] prefers-reduced-motion respected
- [ ] Status messages use live regions where needed
