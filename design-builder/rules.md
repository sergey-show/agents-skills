# Rules — design-builder

1. Hero before below-the-fold — do not decorate the fold last.
2. Do not claim GATE PASS with open Floor FAILs.
3. Waive Reflex only with id + evidence + page-specific reason; never waive Floor.
4. Do not invent material to fill the page.
5. Do not game checkers (headless detects, mass aria hacks).
6. Rounds exhausted: stop silent polish; report OPEN findings.
7. Only the user ends a build early as DONE.
8. Preserve existing design systems; tokens append, don't shadow randomly.
9. Reduced-motion and focus-visible are part of the build, not polish-later.
10. Verify at least one desktop and one phone width before finish.
