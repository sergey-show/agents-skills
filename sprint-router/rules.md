# Rules — sprint-router

1. Recommend existing catalog skills before inventing new ones.
2. Load one primary skill at a time unless orchestrator mode is explicit.
3. Do not execute the specialist workflow here — hand off.
4. If intent is ambiguous, ask one clarifying question, not five.
5. Keep recommendations harness-agnostic.
