# Tools — change-impact

- `filesystem.read` / `search.code` — real callers, imports, schemas

## Optional
- `git.ops` — diff vs plan

## Levels
- **lite** — verbal blast radius in chat
- **full** (default) — structured impact sections
- **ultra** — + post-diff alignment report
